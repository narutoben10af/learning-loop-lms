# Security Policy

## Supported status

Learning Loop LMS is a public pilot/prototype, not a production service. No version is currently supported for production student data.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting feature when enabled. Until then, contact the repository owner privately through the contact route in the owner's GitHub profile. Do not open a public issue for a vulnerability or include credentials, student data, or exploit details in public discussions.

Include affected commit/version, impact, reproduction steps using synthetic data, and a suggested mitigation if known. Maintainers will acknowledge a credible report as soon as practical and coordinate disclosure after a fix.

## Immediate escalation

If real student data, credentials, access tokens, provider keys, or cross-tenant access are exposed, stop testing, preserve only minimal evidence, revoke affected access where authorised, and contact the owner privately. Never copy exposed data into an issue, PR, test fixture, log, or screenshot.
